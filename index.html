支持的 AI 工具

SnapTab 是 MCP 工具，安装后以下工具可直接调用。

  • Claude 桌面版
  • Claude Code
  • Codex
  • DeepSeek Harness
  • WorkBuddy

Windows 10 / 11 和 M 系列芯片的 Mac 都能用。其他支持 MCP 的 AI 工具也可以手动接入。

核心功能

AI 负责理解需求，统计计算由 SnapTab 引擎完成，结果可复核。

显著性检验

比例用 Z 检验，均值用 Welch T 检验，加权数据按有效样本量计算。结果以字母标在表内。

63%BC

一线城市满意度，显著高于二线、三线及以下

SPSS 数据读取

读取 .sav 的变量标签和选项标签，自动识别单选、多选、量表和评分矩阵。

Spec 起草与检查

按数据生成 Spec 初稿，跑表前逐条检查。Spec 为 Excel 格式，可手动修改。

结果解读

报表生成后，AI 可直接读取结果，列出显著变化，整理成文字。

“和上期相比，品牌C 的认知度从 45% 升到 62%，显著上升。”

使用步骤

  1. 安装

    Claude 桌面版用户下载 .mcpb，双击安装。Codex 等工具的用户下载通用版，解压后运行“配置到AI工具”。

  2. 激活

    重启 AI 工具，在对话中输入：激活 SnapTab，激活码是 ACT1-……

  3. 提需求

    例如：给这个文件夹里的数据跑一版交叉表，按城市级别分列
